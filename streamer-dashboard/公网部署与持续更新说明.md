## 一、如何自行启动公网访问（免费方案）

本方案使用 [localtunnel](https://localtunnel.me) 免费内网穿透，无需注册账号、无需购买服务器，适合临时外出查看数据。

### 前置条件
1. 已双击运行 `server\启动数据同步服务.bat`，服务在 `http://localhost:8787` 正常运行。
2. 本机能访问公网（用于 localtunnel 建立隧道）。

### 操作步骤

**方式 A：双击运行（推荐）**

```
server\启动公网隧道.bat
```

运行后会自动生成一个 `https://xxxx.loca.lt` 的公网链接，手机/外部浏览器打开即可。

**方式 B：命令行**

```bash
cd "E:\WorkBuddy\线下主播管理后台\streamer-dashboard"
npx --yes localtunnel --port 8787
```

### 注意事项
- 首次访问 localtunnel 链接时，可能会出现一个 **IP 白名单确认页**，按页面提示点击按钮即可。
- localtunnel 免费链接**不固定**，每次重启隧道都会变化。
- 如需固定域名，可使用 ngrok（需注册并配置自定义域名）或购买云服务器部署。

## 二、长期稳定的部署方案

### 方案 1：云服务器（推荐长期）

1. 购买一台支持 Windows 或 Linux 的云服务器（腾讯云、阿里云等）。
2. 将 `streamer-dashboard` 文件夹上传到服务器。
3. 服务器上安装 Chrome/Edge，并在 `server\config.json` 中配置 `chromePath`。
4. 运行 `server\启动数据同步服务.bat`（Windows）或 `node server/index.js`（Linux）。
5. 通过服务器公网 IP + 8787 端口访问，或配置 Nginx/Apache 反向代理到 80/443 端口。

### 方案 2：Cloudflare Tunnel（免费、固定域名）

1. 注册 Cloudflare 账号并添加一个域名。
2. 在服务器上下载安装 `cloudflared`。
3. 执行 `cloudflared tunnel --url http://localhost:8787`。
4. 绑定固定子域名，即可得到长期公网地址。

## 三、版本机制与持续更新

### 当前版本

前端版本号：`v1.0.0`

版本信息会自动写入：
- `public/version.json`（开发/构建产物）
- `dist/version.json`（生产环境）
- 服务端接口：`GET /api/version`

### 构建时自动生成版本

每次执行 `npm run build` 时，会先运行 `node scripts/write-version.mjs`，自动从 `package.json` 读取版本号并写入 `public/version.json`。

### 如何发布新版本

1. 修改 `package.json` 中的 `version` 字段（如 `1.0.0` → `1.1.0`）。
2. 重新构建：
   ```bash
   npm run build
   ```
3. 重启 `server\启动数据同步服务.bat`（服务端会读取新的 `package.json` 版本）。
4. 刷新浏览器页面，Header 右上角会显示新的版本号。

### 检查更新

页面 Header 右上角显示当前版本号：
- 灰色徽章：前端版本与本地版本一致。
- 黄色徽章：检测到服务端版本与前端版本不一致，提示需要刷新/更新。

## 五、故障排查

### 公网链接打不开
1. 确认 `server\启动数据同步服务.bat` 窗口没有关闭。
2. 确认隧道窗口没有关闭。
3. 首次访问 localtunnel 链接时，可能需要先完成 IP 白名单确认页。

### 版本号不更新
1. 重新执行 `npm run build`。
2. 重启数据同步服务。
3. 强制刷新浏览器（Ctrl+F5）。
